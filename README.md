# Typhoon Roasters — 3D Configurator

Interactive 3D color configurator for Typhoon roasters. The public page is a
static HTML/CSS/JS app built on Three.js.

## Main files

| File | Purpose |
|------|---------|
| `index.html` | User-facing configurator: model selector, RAL color picker, offer modal |
| `admin.html` | Admin mesh-assignment console and config export |
| `config-10pro.json` | Mesh/material assignments for Typhoon 10 PRO |
| `config-5pro.json` | Mesh/material assignments for Typhoon 5 PRO |
| `config-2pro.json` | Mesh/material assignments for Typhoon 2.5 PRO |
| `*.web.glb` | Optimized desktop GLB models |
| `*.mobile.glb` | Optimized mobile GLB models with smaller embedded texture |

## Model sources and optimization

Original/source GLB files are kept locally for rollback and future optimization:

- `new-roaster-3.glb` — Typhoon 10 PRO source
- `new-roaster-2.glb` — Typhoon 5 PRO source
- `2.5.glb` — Typhoon 2.5 PRO source
- `1.glb`, `new-roaster-1.glb`, `1_original_backup.glb` — legacy/backup files

The public page uses optimized GLBs generated by:

```bash
python3 scripts/optimize-glb-textures.py new-roaster-3.glb new-roaster-3.web.glb --quality 85
python3 scripts/optimize-glb-textures.py new-roaster-3.glb new-roaster-3.mobile.glb --quality 85 --max-size 1536
```

Repeat for `new-roaster-2.glb` and `2.5.glb`.

The script keeps geometry and mesh names intact. It only converts embedded PNG
textures without alpha to JPEG; mobile variants additionally downscale the large
texture. This preserves compatibility with the existing material config JSON.

## Local run

Do not open `index.html` via `file://`; GLB and config loading require a web
server.

```bash
python3 -m http.server 8765
```

Then open:

- User page: `http://localhost:8765/`
- Admin page: `http://localhost:8765/admin.html`

## Deployment

This is a static site. The Vercel config uses the project root as output:

```json
{
  "buildCommand": "",
  "outputDirectory": "."
}
```

`.vercelignore` excludes source/backup GLB files and local tooling so production
deploys only the optimized public assets.

## Updating material assignments

1. Open `http://localhost:8765/admin.html`.
2. Use the console panel to reassign meshes.
3. Download or copy the generated config JSON.
4. Replace the matching model config file:
   - `config-10pro.json`
   - `config-5pro.json`
   - `config-2pro.json`
