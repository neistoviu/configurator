Export baked GLB models

Loads each roaster exactly as the configurator does — same config, same material rules, same default paint — then exports a self-contained GLB with those colours baked in. The result needs no config file and no recolouring code: drop it into any 3D viewer and it looks right.

Geometry comes out uncompressed here; run scripts/bake-models.sh afterwards to re-compress.
